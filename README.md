# API RESTful de Productos - Laboratorio 10

Este proyecto es una API RESTful desarrollada como parte de la práctica del Laboratorio 10 para el curso de Desarrollo de Aplicaciones Web (IS093A). Implementa un backend moderno con Node.js y Express, conectado a una base de datos relacional MySQL. Además, incluye una interfaz web básica (Frontend) para demostrar el flujo Fullstack.

## 🛠️ Tecnologías Utilizadas
*   **Node.js** (v20+ / v26)
*   **Express.js** - Framework para el servidor web y enrutamiento.
*   **MySQL** (incluido en XAMPP) - Sistema de gestión de bases de datos.
*   **mysql2/promise** - Cliente de MySQL para Node.js con soporte para Promesas y `async/await`.
*   **dotenv** - Gestión de variables de entorno.
*   **cors** - Middleware para permitir peticiones cruzadas.
*   **HTML/JS Vanilla** - Interfaz de usuario para consumir la API.

## 📋 Prerrequisitos
Antes de ejecutar el proyecto, asegúrate de tener instalado:
1.  [Node.js](https://nodejs.org/) (versión LTS 20 o superior).
2.  Servidor de base de datos MySQL (se recomienda XAMPP o Laragon).
3.  Un cliente para probar APIs (Postman, Insomnia o Thunder Client en VS Code).
